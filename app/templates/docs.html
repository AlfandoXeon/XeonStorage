04

{{ t('public_title') }}

{{ t('public_desc') }}

Direct Raw Hotlink: GET {{ request.base_url }}f/{file_id}.{ext}

Gunakan tautan ini untuk tag <img src="...">, <video src="...">, bot Discord, chatbot otomasi, maupun skrip CLI. Mendukung CORS penuh (Access-Control-Allow-Origin: *).

Web Gallery Viewer: GET {{ request.base_url }}v/{file_id}

Halaman antarmuka web interaktif yang menyajikan media player bawaan, pratinjau gambar zoomable, rincian ukuran file, dan tombol download yang user-friendly.

06

{{ t('cache_title') }}

{{ t('cache_desc') }}

Algoritma LRU Disk

Berkas paling populer dipertahankan di storage NVMe lokal ultra-cepat, sementara berkas jarang terakses digantikan secara otomatis untuk menjaga ketersediaan ruang.

ETag 304 Not Modified

Jika browser Anda telah mengunduh berkas sebelumnya, server akan mengembalikan respon 304 dengan ukuran 0 byte, menghemat kuota internet dan menyajikan data dengan latensi instan.

{{ t('examples_title') }}

Python (Requests): 
import requests

API_KEY = "XST_your_api_key_here"
BASE_URL = "{{ request.base_url }}"
headers = {"Authorization": f"Bearer {API_KEY}"}

# 1. Upload Berkas
with open("sample.mp4", "rb") as f:
    res = requests.post(f"{BASE_URL}api/v1/files", headers=headers, files={"file": f})
    data = res.json()
    print("Direct URL:", data["data"]["url"])
    file_id = data["data"]["id"]

# 2. Ambil Metadata
info = requests.get(f"{BASE_URL}api/v1/files/{file_id}", headers=headers).json()
print("Nama Berkas:", info["data"]["original_name"])

# 3. Riwayat Akun
files = requests.get(f"{BASE_URL}api/v1/me/files", headers=headers).json()
print("Total Berkas:", len(files["data"]))
JavaScript / Node.js (Fetch & FormData): 
import fs from 'fs';
import FormData from 'form-data';
import fetch from 'node-fetch';

const API_KEY = 'XST_your_api_key_here';
const BASE_URL = '{{ request.base_url }}';

async function uploadMedia(filePath) {
  const form = new FormData();
  form.append('file', fs.createReadStream(filePath));

  const response = await fetch(`${BASE_URL}api/v1/files`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${API_KEY}`,
      ...form.getHeaders()
    },
    body: form
  });

  const result = await response.json();
  console.log('Direct Hotlink:', result.data.url);
}

uploadMedia('photo.png');
PHP (cURL): 
<?php
$apiKey = "XST_your_api_key_here";
$apiUrl = "{{ request.base_url }}api/v1/files";

$ch = curl_init();
$cfile = new CURLFile('document.pdf', 'application/pdf', 'document.pdf');

curl_setopt($ch, CURLOPT_URL, $apiUrl);
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, ['file' => $cfile]);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "Authorization: Bearer " . $apiKey
]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);
echo "Direct Link: " . $result['data']['url'];
?>
Golang (net/http): 
package main

import (
	"bytes"
	"fmt"
	"io"
	"mime/multipart"
	"net/http"
	"os"
)

func main() {
	var b bytes.Buffer
	w := multipart.NewWriter(&b)
	f, _ := os.Open("video.mp4")
	defer f.Close()
	fw, _ := w.CreateFormFile("file", "video.mp4")
	io.Copy(fw, f)
	w.Close()

	req, _ := http.NewRequest("POST", "{{ request.base_url }}api/v1/files", &b)
	req.Header.Set("Authorization", "Bearer XST_your_api_key")
	req.Header.Set("Content-Type", w.FormDataContentType())

	client := &http.Client{}
	res, _ := client.Do(req)
	defer res.Body.Close()
	fmt.Println("Status:", res.Status)
}

{{ t('errors_title') }}

Status Deskripsi Singkat Penyebab & Solusi Penanganan
200 OK Sukses Permintaan berhasil diproses dan mengembalikan payload JSON valid.
206 Partial Content Media Range Seeking Normal saat pemutar video/audio meminta rentang byte tertentu.
304 Not Modified ETag Cache Hit File sudah ada di cache browser, 0 byte bandwidth server terpakai.
400 Bad Request Parameter Tidak Valid Field 'file' kosong atau tipe form-data tidak valid.
401 Unauthorized API Key Hilang / Salah Periksa header Authorization: Bearer XST_...
404 Not Found File ID Tidak Ditemukan ID berkas salah atau telah dihapus oleh pemiliknya.
413 Payload Too Large Ukuran Melebihi 1.5 GB Kompresi berkas atau pisahkan menjadi beberapa bagian di bawah 1.5 GB.
500 Cluster Error Gangguan Node Cloud Kesalahan internal koneksi kluster terdistribusi, sistem akan me-retry otomatis.

{{ t('faq_dev_title') }}

Apakah direct link terkena batasan Cross-Origin Resource Sharing (CORS)?

Tidak sama sekali. Semua endpoint publik menyertakan header Access-Control-Allow-Origin: * sehingga dapat dipanggil langsung dari domain frontend mana pun.

Apakah file gambar atau video yang saya unggah akan di-kompresi ulang?

Tidak. XeonStorage menjamin retensi berkas bit-for-bit lossless tanpa penurunan resolusi, bitrate, atau metadata EXIF berkas asli Anda.

Berapa banyak API Key yang bisa saya buat?

Anda dapat membuat multi-key secara mandiri di halaman dashboard untuk memisahkan token bot staging, bot produksi, maupun script pribadi Anda.
